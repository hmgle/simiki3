# 路线图

Simiki3 当前处于 pre-alpha 阶段。命令 `simiki3 goals` 会输出 CLI 中的实时里程碑表。

| 里程碑 | 状态 |
| --- | --- |
| CLI 和打包 | 已实现：init、new、build、theme、update、validate、serve 和 migrate。 |
| 站点初始化 | 已实现：项目生成器和内置主题。 |
| 内容流水线 | 已实现：Markdown、目录、Atom feed 和附件。 |
| 预览和监控 | 已实现：本地服务器和增量重建。 |
| 部署辅助 | 计划中：从 Simiki 移植 rsync、Git 和 FTP 部署支持。 |
| 发布加固 | 计划中：CI、文档和第一个正式版本。 |

当前开发进展请查看 [GitHub 仓库](https://github.com/hmgle/simiki3)。
