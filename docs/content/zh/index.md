# Simiki3

Simiki3 是受 [Simiki](https://github.com/tankywoo/simiki) 启发的现代 Python 3 静态 Wiki 生成器。它可以把带有 YAML front matter 的 Markdown 文件转换为包含页面目录、Atom feed、主题和附件的完整静态站点。

## 从这里开始

1. [安装 Simiki3](/simiki3/zh/getting-started/installation.html)。
2. 按照[快速开始](/simiki3/zh/getting-started/quick-start.html)创建站点。
3. 需要查询命令时参考 [CLI 参考](/simiki3/zh/reference/cli.html)。

- [迁移](/simiki3/zh/guides/migration.html) — 安全迁移旧版 Simiki 站点。
