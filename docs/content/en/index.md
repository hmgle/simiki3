# Simiki3

Simiki3 is a modern Python 3 static wiki generator inspired by [Simiki](https://github.com/tankywoo/simiki). It turns Markdown files with YAML front matter into a self-contained site with a page catalog, Atom feed, themes, and attachments.

## Start here

1. [Install Simiki3](/simiki3/en/getting-started/installation.html).
2. Follow the [quick start](/simiki3/en/getting-started/quick-start.html) to create a site.
3. Use the [CLI reference](/simiki3/en/reference/cli.html) when you need a command detail.

## Explore the guide

- [Configuration](/simiki3/en/reference/configuration.html) — configure URLs, paths, themes, and metadata.
- [Themes](/simiki3/en/guides/themes.html) — customize the generated site.
- [Migration](/simiki3/en/guides/migration.html) — move a legacy Simiki site safely.
- [Development](/simiki3/en/development.html) — run tests and work on Simiki3 itself.
- [Deployment](/simiki3/en/deployment.html) — publish a generated site with GitHub Pages.
