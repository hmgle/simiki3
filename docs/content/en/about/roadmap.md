# Roadmap

Simiki3 is currently pre-alpha. The command `simiki3 goals` prints the live milestone table from the CLI.

| Milestone | Status |
| --- | --- |
| CLI and packaging | Implemented: init, new, build, theme, update, validate, serve, and migrate. |
| Site initialization | Implemented: project generator and bundled themes. |
| Content pipeline | Implemented: Markdown, catalog, Atom feed, and attachments. |
| Preview and watch | Implemented: local server with incremental rebuilds. |
| Deployment helpers | Planned: port rsync, Git, and FTP deployment support from Simiki. |
| Release hardening | Planned: CI, documentation, and the first release. |

See the [GitHub repository](https://github.com/hmgle/simiki3) for current development activity.
